# Architecture decision records

This folder records the significant design decisions for `@ocoda/event-sourcing`, one file per decision. The files are numbered in order.

| ADR | Title | Status |
| --- | --- | --- |
| [0001](./0001-v4-core-api.md) | v4 core API | Proposed |
| [0002](./0002-schema-v2.md) | Schema v2 (global position, catalog, migration) | Proposed |

To add a decision, copy the structure of an existing ADR, take the next number, and add a row to this table. Each ADR's status is one of:

- **Proposed**
- **Accepted**
- **Superseded by NNNN**
