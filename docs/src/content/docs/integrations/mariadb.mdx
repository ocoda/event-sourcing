`@ocoda/event-sourcing-mariadb` provides the `MariaDBEventStore` and the `MariaDBSnapshotStore`. It needs the `mariadb` driver, which is a peer dependency: see [Installation](/start/install) and [Database drivers are peer dependencies](/upgrading/v4#drivers).

<Aside type="note" title="Schema v2 lands in a later prerelease">
This page will describe the 4.0 schema, its limits and capabilities, the privileges the store needs, and how to migrate 3.x tables. Until then, see [MariaDB schema v2](/upgrading/v4#mariadb-schema-v2) in the 4.0 migration guide.
</Aside>
