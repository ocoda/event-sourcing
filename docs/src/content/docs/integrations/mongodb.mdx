`@ocoda/event-sourcing-mongodb` provides the `MongoDBEventStore` and the `MongoDBSnapshotStore`. It needs the `mongodb` driver, which is a peer dependency: see [Installation](/start/install) and [Database drivers are peer dependencies](/upgrading/v4#drivers).

<Aside type="note" title="Schema v2 lands in a later prerelease">
This page will describe the 4.0 schema, its limits, the capabilities of each MongoDB topology, the privileges the store needs, and how to migrate 3.x collections. Until then, see [MongoDB schema v2](/upgrading/v4#mongodb-schema-v2) in the 4.0 migration guide.
</Aside>
